# Code of conduct

SecureFolio follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, pull requests and discussions is expected to keep to it.

To report behavior that breaks it, email the maintainers at Vaalmi, contact@vaalmi.com. Reports are kept confidential.
